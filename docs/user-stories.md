# User Stories

## US-01: RFID Login

**User Story**

As a student, I want to tap my RFID card so that I can access the borrowing system.

**Acceptance Criteria**
- Student taps a valid RFID card.
- Dashboard opens.
- Invalid RFID shows an error.

---

## US-02: Search Equipment

**User Story**

As a student, I want to search equipment so that I can find the item I need.

**Acceptance Criteria**
- Student can search equipment.
- Matching results are shown.
- Student can open equipment details.

---

## US-03: View Equipment Details

**User Story**

As a student, I want to view equipment details so that I know if it is available.

**Acceptance Criteria**
- Equipment name is shown.
- Description is displayed.
- Available quantity is displayed.

---

## US-04: AI Recommendation

**User Story**

As a student, I want to receive AI recommendations so that I know what other equipment I might need.

**Acceptance Criteria**
- AI recommends related equipment.
- Recommendations are based on previous borrowing records.
- Student can add recommended equipment.

---

## US-05: Add to Borrow List

**User Story**

As a student, I want to add equipment to my borrow list so that I can borrow multiple items.

**Acceptance Criteria**
- Student can add equipment.
- Borrow list updates.
- Student can remove equipment.

---

## US-06: Submit Borrow Request

**User Story**

As a student, I want to submit my borrow request so that it can be reviewed.

**Acceptance Criteria**
- Request is submitted.
- Student receives confirmation.
- Request status becomes Pending.

---

## US-07: Approve Borrow Request

**User Story**

As a laboratory technician, I want to approve or reject requests so that equipment is properly managed.

**Acceptance Criteria**
- Technician can approve requests.
- Technician can reject requests.
- Student receives the result.

---

## US-08: Update Inventory

**User Story**

As a laboratory technician, I want the inventory to update automatically so that records stay accurate.

**Acceptance Criteria**
- Inventory updates after approval.
- Available quantity changes.
- Borrow history is saved.
