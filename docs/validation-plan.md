# Initial Validation Plan

## Objective

Check if the system makes laboratory equipment borrowing easier and more organized.

## Validation Method

- Test RFID login.
- Test equipment search.
- Test AI recommendations.
- Test borrow request submission.
- Test technician approval.
- Check if inventory updates correctly.

## Success Criteria

- Students can log in using RFID.
- Equipment can be searched and borrowed.
- AI shows helpful recommendations.
- Technician can approve requests.
- Inventory updates after approval.
